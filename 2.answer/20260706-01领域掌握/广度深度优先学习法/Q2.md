# 问题

```
如何在广度优先和深度优先之间进行切换？
```

# 核心思路
切换不是凭感觉“想学深就深、想学广就广”，而是建立一套**触发条件 + 固定动作 + 止损规则**。本质上：**广度是“测绘地图”，深度是“钻井勘探”；每次切换都带着明确目的，而不是随机跳来跳去**。
先给一个极简的切换口诀：
> 广度阶段：找连接、标依赖、划边界，不纠缠难点；
> 深度阶段：顺依赖、拆证据、做验证，不随便开新分支；
> 切换的开关来自三类信号：【卡住了】【地图缺一块】【当前目标完成】

下面分成：切换时机、切换流程、止损规则、实操工具、常见坑。

## 一、什么时候：从广度 → 深度（测绘完一块，开始钻井）
触发信号（满足其一就可以切深度）：
1. 你已经能回答：这个概念属于哪个子模块、它解决什么问题、它前置依赖是哪 1~2 个基础概念；
2. 这个概念是**主线枢纽节点**，后面大量内容都建立在它之上（不是边角扩展）；
3. 你的目标要落地：写代码、做题、推导、看懂论文、做方案，只知道名词不够。

✅ 切换动作（广度收尾，转入深度）
1. 在你的知识地图上圈出这个节点，写下它的前置依赖清单；**先确认依赖项你已经有基础认知，依赖缺了就先补依赖（回到广度）**；
2. 给这次深度探索设一个明确、有限的目标，不要写“吃透XX”，要写可终止目标：
   - 例：梯度下降深度目标：能手动推导SGD、写出简易代码、说出3个失效场景；
   - 不要：搞懂所有优化算法（这个是广度任务）
3. 划定本次深度的边界：哪些变体、高阶拓展，标记为【本次不深挖，后置】；
4. 进入深度模式：沿着定义→原理→例子→反例→实现/推导→缺陷，线性往下走。

> 举例：广度扫机器学习时，看到“梯度下降”，知道它是优化器、用来找损失最小值，和导数、损失函数相关。它是枢纽节点，于是切深度，限定目标：搞懂SGD基础，Adam、二阶优化标记后置。

## 二、什么时候：从深度 → 广度（钻井钻到一个节点，退回看全局）
触发信号（满足其一就切回广度）：
1. **深度卡死**：卡在某个细节很久，而且这个细节不是当前深度目标的核心（属于边缘分支）；
   > 比如你在啃SGD，卡在Hessian矩阵数学性质，但你的目标只是实现SGD，这就属于支线，及时上浮回广度；
2. 你把**预先设定的深度目标完成了**；一口井打完，不要无限往下钻无穷变体；
3. 深度学习中，频繁出现陌生名词，且这些名词会影响你理解这个节点的定位；
   > 你在深挖过拟合，频繁听到偏差、方差、泛化，但之前地图里这两块是空的，需要上浮，用广度补这几个相邻概念；
4. 你需要判断优先级：现在这个分支值不值得继续投入，有没有更主线的内容。

✅ 切换动作（深度上浮，转入广度）
1. 立刻做一次小结：这个节点学到了什么、它的上下游是谁、它的适用边界；把结论回填到知识地图；
2. 暂停当前支线，**不继续往下钻更深的变体**，给卡住的细节打标签【待后续深度】；
3. 广度任务聚焦：只补刚刚暴露出来的相邻、关联概念，不是漫无目的从头再扫一遍整个领域；
4. 重新评估主线：现在地图上哪个节点是下一个优先级最高的枢纽，准备下一轮深度。

> 举例：你深挖SGD，看到Nesterov动量，越挖越偏向凸优化收敛证明，偏离了你原本“实现优化器”的目标 → 上浮回广度，把动量优化器标记为一类，先去看偏差方差、正则化这些相邻主线概念。

## 三、一套可直接用的循环节奏（小循环，而不是一次大广度+一次大深度）
不要做成：花1个月纯广度，再连续3个月纯深度。这种很容易脱节。
推荐**小粒度循环**：
1. 【短广度（30min~半天）】：扫一簇相邻概念，画局部子图，标出枢纽、依赖；
2. 【切深度】：挑其中一个枢纽，设定有限目标，深挖；
3. 【深度结束/触发卡点 → 切广度复盘】：回填地图，补关联概念，重新选下一个枢纽；
4. 重复。

> 大广度（全景测绘）只在最开头做一次，后续绝大多数广度都是**局部广度**，不是全领域重扫。这点非常关键，很多人在这里浪费时间。

## 四、硬性止损规则（防止两种极端）
### 深度模式下的止损（防止钻牛角尖）
固定一个时间阈值，比如：
> 在一个支线细节上消耗超过预设时长（比如2小时），且它不在本次深度目标清单里 → 强制上浮，切广度，标记后置。

判断问句：**就算我现在弄懂这个细节，会不会影响我完成这次预设的深度目标？**
- 不影响 → 放一放；
- 影响 → 那它本身就是主线，继续深度。

### 广度模式下的止损（防止无限收集名词）
广度阶段禁止深挖推导、源码；
判断问句：**我现在是不是在尝试搞懂内部原理/证明？**
- 是 → 越界了，先记下来，留到深度阶段；
广度有截止标准：能说出每个概念【作用+输入输出+和1~2个邻居的关系】就达标，立刻停止广度，准备切入深度。

## 五、辅助工具，降低切换成本
你需要一张持续维护的知识图（简单就行，思维导图/笔记大纲都可以），每个节点带上3个标签：
- 🗺️【广度已完成】：知道定位、关联，未深挖
- ⛏️【深度进行中】：当前钻井节点
- ✅【深度已完成】：已经完成本轮限定深度目标
- 📌【待深挖支线】：当时卡住、延后的细节

切换本质就是**修改标签，移动当前焦点**。
每次切换的时候强制写一句话日志：
- 广度→深度：本次深度目标是什么，边界到哪里，哪些不看；
- 深度→广度：我挖到了什么，现在缺哪些相邻概念，接下来广度要补哪几个。

## 六、两种容易混淆的坏切换方式，避开
1. **随机跳跃式切换**：学一点A深度，没做完，突然跳到B广度，再跳到C深度。没有目标、没有边界，知识是一堆碎片；
2. **单向锁死**：一直广度（收藏党）或者一直深度（死磕一个点），就是我们前面说的两个大坑；
3. **深度目标无限膨胀**：本来只想弄懂基础SGD，结果一路延伸到凸分析、随机过程、高阶优化，目标不断扩大，永远结束不了。

## 七、举一个完整的连贯例子（线性代数入门）
1. 初始全景广度：向量、矩阵、线性变换、行列式、特征值、秩、空间，每个只搞懂大概是干嘛的，互相什么关系 → 全部标记🗺️；
2. 判断：**秩是枢纽节点**，切深度；设定目标：秩的定义、行秩=列秩、秩的几何含义、满秩的意义；奇异值分解标记📌后置；
3. 挖到一半，发现自己不懂“向量空间”，而它是秩的前置 → 上浮，切局部广度，快速补齐向量空间、子空间；
4. 向量空间广度达标，再切回深度继续啃秩；
5. 秩深度目标完成✅，回填地图；
6. 回到地图，下一个枢纽是特征值，开启下一轮深度。

## 一句话总结切换逻辑
**广度是“看连接、定优先级”，深度是“啃单点、做验证”；
从广度进深度，靠【枢纽节点 + 落地需求】；从深度退回广度，靠【依赖缺失 / 支线卡点 / 原定深度目标完成】；
并且每一次深度，都必须带一个可终止的有限目标。**
