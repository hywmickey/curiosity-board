# 【领域名称】知识体系笔记
学习策略：广度测绘 → 定点深度攻坚 → 回填地图，循环迭代
协作模式：
- 我：主编、校验人、理解主体，手写【我的复述】
- LLM：助理，提供素材、反例、自测题、审计排查；输出仅为草稿，必须校验后入库
状态标签定义：
🗺️ 已测绘（广度完成，知道定位与依赖，未深挖）
⛏️ 攻坚中（当前深度学习节点）
✅ 本轮达标（完成预设深度目标，通过自测）
📌 后置（支线问题，暂不展开，放入疑问队列）

切换规则：
1. 看到【缺失前置概念】→ 切局部广度，补地图
2. 当前节点完成预设深度目标 → 回填地图，回到广度视角选下一个枢纽
3. 在支线细节超时卡壳、且不影响本轮目标 → 标记 📌 后置
4. 定期审计：检查依赖环路、概念冲突、理解浮于表面

入库铁则：
1. 所有进入卡片的内容，必须经过我校验；LLM原文不能直接当作事实
2. 定义、公式、结论尽量带上可信来源；无法核验时标记【未验证】
3. 【我的复述】必须由本人手写，禁止直接复制大模型输出
