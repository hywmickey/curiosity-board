## 文件清单

README.md
00-MAP.md（知识地图，广度核心）
01-QUESTIONS.md（疑问队列，切换触发器）
02-SOURCES.md（可信来源，防幻觉）
03-PROMPTS.md（可直接复制给大模型的提示词）
CHANGELOG.md（变更记录，git 配套）
concepts / 示例卡片.md（标准卡片模板，新建概念直接复制这个）


## 快速上手步骤

1. 新建这个目录，把上面全部粘贴进去；把 `<你的领域名>` 替换成你现在要学的方向（比如：微积分 / Go 并发 / 深度学习基础）
2. 先用【提示 1】跑一轮，拿到初始骨架，填入 `00-MAP.md`
3. 从地图挑一个高枢纽节点，新建一张 concept 卡片，标记 status:⛏️
4. 使用【提示 2】做深度素材收集，再使用【提示 3】处理中途疑问，疑问扔进 `01-QUESTIONS.md`
5. 素材到手后，**自己写【我的复述】**，校验来源，合格后标记✅
6. 每隔几张卡片，调用【提示 4】审计一次地图，发现断链、矛盾就回到广度补全
